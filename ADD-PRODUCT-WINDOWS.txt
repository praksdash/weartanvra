QUICK PRODUCT UPLOAD

1. Open:
   products\oversized\
   OR
   products\regular\

2. Create ONE folder for ONE product.
   Example:
   products\oversized\rojana-ek-ghanta\

3. Copy all extracted product pictures into that folder.

4. Optional:
   Copy product.json from another product and edit name/price.

5. Push:
   git add -A
   git commit -m "Add new WEAR TANVRA products"
   git push origin main

6. GitHub Actions will automatically build the product catalogue and publish the website.

FIRST-TIME GITHUB SETTING:
Repository > Settings > Pages > Source > GitHub Actions
