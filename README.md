# WEAR TANVRA — Static GitHub Site

Standalone pre-launch/marketing website. It does **not** process payments or COD.

## GitHub Pages
1. Push these files to a normal GitHub repository.
2. Settings → Pages → Deploy from `main` / root.
3. Keep the default GitHub Pages URL if `weartanvra.com` is being used by Shopify.
4. Only rename `CNAME.example` to `CNAME` if you intentionally want the custom domain to point to GitHub instead of Shopify.

## Before public launch
- Replace blank supplier mockups with final WEAR TANVRA designs/sample photos.
- Replace Coming Soon buttons with the desired Shopify product URLs if using this as a landing site.
- Confirm prices/stock with T-Adda because their terms say pricing and availability can change.
