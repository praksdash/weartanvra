- Mobile logo was visually undersized.
- Navigation used a simple stacked block without a proper drawer.

- Menu lacked accessible open/close state and body scroll lock.

- Hamburger left / larger TANVRA logo centered / BAG right.
- 48px hamburger and close targets.
- Slide-out premium cream mobile drawer.
- Dimmed backdrop.
- Accessible aria-expanded / aria-hidden state.
- Escape key closes menu.
- Backdrop tap closes menu.
- Link selection closes menu.
- Body scroll locks while menu is open.
- Desktop navigation preserved.
